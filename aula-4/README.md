Aula 4 

Processo 1 - Registro de pedidos

Requisito 1

O sistema deve permitir que o vendedor registre um novo pedido informando os produtos, suas respectivas quantidades e o cliente.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Formulário ou modelo atual utilizado para registrar pedidos. Fonte não humana, categoria documentação.

Requisito 2

O sistema deve calcular automaticamente o valor total do pedido com base nos produtos e quantidades informados.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Política comercial da empresa sobre preços e cálculos de venda. Fonte não humana, categoria documentação.

Requisito 3

O sistema deve registrar a forma de pagamento escolhida no momento da venda.

Fonte 1. Entrevista com o vendedor. Fonte humana, nível operacional, classe de usuário vendedor.

Fonte 2. Política comercial sobre formas de pagamento aceitas. Fonte não humana, categoria documentação.

Processo 2 - Cadastro e remoção de produtos

Requisito 1

O sistema deve permitir que o administrador cadastre um produto informando nome, descrição, preço e código de identificação.

Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

Fonte 2. Cadastro ou catálogo de produtos utilizado atualmente pela empresa. Fonte não humana, categoria documentação.

Requisito 2

O sistema deve permitir que o administrador altere os dados de um produto já cadastrado.

Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

Fonte 2. Procedimentos internos para manutenção do cadastro de produtos. Fonte não humana, categoria documentação.

Requisito 3

O sistema deve permitir que o administrador remova um produto que não seja mais comercializado.

Fonte 1. Entrevista com o administrador. Fonte humana, nível operacional, classe de usuário administrador.

Fonte 2. Política interna para exclusão de produtos do catálogo. Fonte não humana, categoria documentação.

Processo 3 - Controle de estoque

Requisito 1

O sistema deve permitir que o responsável pelo estoque registre a entrada de produtos e suas respectivas quantidades.

Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário responsável pelo estoque.

Fonte 2. Notas fiscais e documentos utilizados para registrar a entrada de mercadorias. Fonte não humana, categoria documentação.

Requisito 2

O sistema deve permitir que o responsável pelo estoque dê baixa na quantidade de produtos após uma saída.

Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário responsável pelo estoque.

Fonte 2. Registros de pedidos e vendas realizados pela empresa. Fonte não humana, categoria documentação.

Requisito 3

O sistema deve atualizar a quantidade disponível de um produto sempre que ocorrer uma entrada ou saída de estoque.

Fonte 1. Entrevista com o responsável pelo estoque. Fonte humana, nível operacional, classe de usuário responsável pelo estoque.

Fonte 2. Procedimento interno de controle de estoque da empresa. Fonte não humana, categoria documentação.
