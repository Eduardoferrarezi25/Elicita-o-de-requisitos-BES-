Aula 6

Empatia

Pergunta de empatia. Por que eu esqueço algumas tarefas que preciso fazer durante a semana mesmo sabendo que tenho que realizá-las?

Definição

Definição. Eu tenho dificuldade para lembrar das tarefas que preciso realizar durante a semana porque elas ficam apenas na minha memória e não tenho um lugar único para organizá-las.

Ideação

Ideia 1. Criar um aplicativo que envie notificações nos horários escolhidos para lembrar das tarefas.

Ideia 2. Criar uma lista de tarefas que organize as atividades por dia e horário.

Ideia 3. Criar um calendário que mostre as tarefas da semana e permita marcar as atividades como concluídas.

Escolha

Ideia escolhida. Criar um aplicativo que envie notificações nos horários escolhidos para lembrar das tarefas.

Histórias de usuário

História de usuário 1. Como usuário, quero cadastrar uma tarefa com data e horário, para receber um lembrete no momento escolhido.

História de usuário 2. Como usuário, quero receber uma notificação quando chegar o horário de uma tarefa, para não esquecer de realizá-la.

História de usuário 3. Como usuário, quero marcar uma tarefa como concluída, para saber quais atividades da minha lista já foram realizadas.

Critérios de aceitação

Critério de aceitação 1. Dado que o usuário cadastrou uma tarefa com data e horário, quando chegar o horário definido, então o sistema deve enviar uma notificação.

Critério de aceitação 2. Dado que o usuário recebeu uma notificação de uma tarefa, quando ele abrir a notificação, então o sistema deve mostrar a tarefa correspondente.

Critério de aceitação 3. Dado que uma tarefa foi realizada, quando o usuário marcar a tarefa como concluída, então o sistema deve indicar que ela foi concluída.
